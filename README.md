# grievances
Personal gripes with various software - no blame attached!

<!-- ------------------------------------------------------------------------------------- -->
## Cosmic

### libcosmic
- Does not support window buttons left
- Does not support unorthodox window button order

### App support
- Yakuake does not work on Fedora in Cosmic due to requiring absent icon themes "Pop-Extra" and "pop-os-branding".
- Does not honour non-Cosmic apps' retained window sizes
- Non-Cosmic windows which dock to a side of the screen, e.g. `guake`, do not dock and cannot be maximised

### Cosmic Terminal
- Supports only a subset of available fonts, excluding Terminus, which is a deal-breaker. Why?! Cosmic Text cannot be the problem, because Terminus and other fonts work fine on Zed. And... why?! It's based on Alacritty, which again has fine support.
- Does not retain window size

### Cosmic Files
- Does not have a compact view
